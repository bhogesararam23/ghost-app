# Code of Conduct

## Our standard

Ghost Network is a student led open source project.

We want contributions to be technically serious, constructive and welcoming.

Examples of expected behaviour:

- be respectful and professional
- discuss the code and technical tradeoffs, not people
- welcome beginners and questions
- give clear feedback
- acknowledge when something is uncertain
- prioritize privacy and security when reviewing sensitive code

Unacceptable behaviour includes harassment, discrimination, threats, personal attacks and deliberate disruption.

## Security related discussions

Do not publish private security vulnerabilities or real secrets in public issues or pull requests.

Follow the process in [SECURITY.md](SECURITY.md).

## Enforcement

Project maintainers may remove comments, close discussions or restrict participation when behaviour violates this code of conduct.

The goal is to keep the project usable for learning, research and serious engineering work.
